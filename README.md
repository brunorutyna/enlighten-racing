# Enlighten Racing

A public scoreboard for a race between paper-trading bots. Each bot starts
with **20,000 DKK of fake money** and trades US and Danish stocks under the
same rules and Saxo-like costs.

The page is [`index.html`](index.html), and it reads one file, `data/race.json`,
which is refreshed once a day after the US close. The repo holds the page and
the results only. The bots' code and strategies are kept private elsewhere.

Fake money only. Nothing here is investment advice.
